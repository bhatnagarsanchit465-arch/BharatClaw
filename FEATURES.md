# BharatClaw Limited Features (Hindi-focused 🇮🇳)

Sirf ye 4 features abhi (UPI baad mein):

1. **WhatsApp Unknown Answers**  
   Unknown messages aane pe automatically smart Hindi reply bhejega (jaise “Namaste, aapka message receive ho gaya. Kya help chahiye?”).

2. **Festival Calendar**  
   Indian festivals auto add karega (Diwali, Holi, Eid, Raksha Bandhan, Janmashtami, birthdays etc.) + reminders set karega.

3. **Email Read + Reply**  
   Important emails padhega, summary bataayega, aur short polite reply bhej sakta hai (Gmail/Outlook safe tareeke se).

4. **Hindi Voice Commands**  
   Phone pe bolke control:  
   “Claw, aaj ke festivals batao”  
   “Claw, email check kar”  
   “Claw, WhatsApp dekho”

**Quick setup hint (jab laptop mile):**  
- Hindi voice on: `openclaw voice --lang hi`  
- Festival skill: `openclaw skills add festival-india`

Bas itna hi! Simple, safe aur desi.
